# lswms_waterpoint

Implementation of the backend waterpoint model using an open-source Python geospatial stack for the Ethiopia water points monitoring platform ([https://rangelandmonitoring.eiar.gov.et/](https://rangelandmonitoring.eiar.gov.et/)).

## 📚 Documentation

For complete setup guides, usage instructions, and detailed API references, please visit official documentation:

👉 **[lswms_waterpoint Documentation](https://liyunet.github.io/lswms_waterpoint_docs/)**

## 🛠️ Requirements

* Python 3.x
* anaconda 
* conda env create -f environment.yml
